# presscorps.seamun.com

Press Corps committee site for [SEAMUN I 2027](https://www.seamun.com/).

Flow matches other SEAMUN microsites:

1. **Vinyl wheel** — pick a committee (logos in `assets/committee-logos/`)
2. **Payment / access gate** — placeholder dove-in-cage unlock (swap later for themed payment)
3. **Committee portal** — topic, allocations, schedule, RoP / position paper / chair report placeholders

## Local preview

```bash
python3 -m http.server 8080
```

Open `http://localhost:8080`.
